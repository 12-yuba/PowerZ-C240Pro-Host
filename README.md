# C240Pro · 上位机（Windows / Android）

通过蓝牙 BLE 读取 Power-Z C240 Pro 测试仪的实时电压 / 电流 / 功率采样，解析 PD 协议报文与线缆 eMarker 信息，并支持导出 XLSX 数据。

**提供 Windows 与 Android 两个版本，共用同一套界面与解析逻辑。**

协议依据微信小程序反编译 + 蓝牙 HCI 抓包**双向验证**得出。本软件只读取设备上报的数据，不写设备、不改固件。

## 功能特性

### 实时监测
- **电压 / 电流 / 功率**三路独立坐标曲线，量级差异大也不会互相压平
- 每路可单独调整「偏移系数」（坐标量程倍数），自由分层显示，不改变真实数值
- 渐变面积填充、明暗双主题（Segoe UI Variable / Fluent 2 设计语言）
- 数值面板 **250ms** 刷新，曲线走 SSE 实时推送，20SPS 下约 100 秒滚动窗口
- 仪表页三张指标卡底部各带一条 400 点迷你趋势线

### 采样率
| 档位 | 指令 | 说明 |
|---|---|---|
| 1 SPS | `0xC4 "111"` | |
| 10 SPS | `0xC4 "112"` | |
| 20 SPS | `0xC4 "113"` | 默认 |

切换后曲线推进速度与导出数据密度同步变化。

### PD 协议分析
- **充电器 PDO 全档位**解码：Fixed / APDO(PPS) / **APDO(SPR AVS 两段电压)**
- **下游实际请求（RDO）**：按 PDO 真实类型解位——PPS 请求用 20mV/50mA 单位，Fixed 请求用 10mA 单位
  - 类型未知时**不猜测**，同时给出两种解并明确标注「类型未确认」
  - 显示「收到于 X 秒前」，区分协商历史与当前实时工作点
- **线缆 eMarker**：厂商 VID、线缆类型、供电能力、速率规格、EPR 支持、Cable VDO
- **报文分析表格**（仿专业分析工具）：
  - 暂停展示（只冻结表格，底层采集继续，恢复后自动补齐）
  - 清空显示 / 自动滚动（仅在已停底部时跟随，可手动上翻）/ 隐藏 GoodCRC / 按消息类型过滤
  - 消息类型着色、V/I 列、Note 解码列、原始 hex 提示

### SPR AVS 两段显示

一个 AVS 档位按规范拆成两段（15V 是分段点）：

```
7   APDO(SPR AVS)
    ↳  9.0 – 15.0 V   2.66 A
    ↳ 15.0 – 20.0 V   2.00 A
```

- 电压上限来自 VDO，下限为 AVS 规范的 9V
- 两段电流由功率反推：`P = maxV × I_high`，低段 `min(3A, P/15)`
- 已用 **40W / 70W 两只真实充电器交叉验证**：40W → 2.66/2.00 A，70W → 3.00/3.00 A（低段被 3A 钳位）

### 数据导出
- 曲线数据与 PD 报文**分两个文件**
- 点击后弹出 **Windows 原生「另存为」对话框**，自选路径与文件名
- 时间轴三列并存：**相对秒**（本地单调时钟从 0 起，不受系统校时影响）+ **本地绝对时间** + **设备计时**（可交叉核对是否中途掉电）
- 电流列取绝对值，另设「电流方向」列保留原始符号信息
- PD 报文文件含两个 sheet：`PD报文` + `电源能力与线缆`

### 窗口体验
- 独立原生窗口（无系统标题栏，顶部自绘标题栏）
- 标题栏拖动由 Windows 原生循环处理，跟手无延迟
- 拖到屏幕顶部 = 最大化，拖到左/右边缘 = 半屏，均按工作区计算**不遮挡任务栏**
- 四边四角可拖拽缩放，支持 175% 等高 DPI 缩放
- 单实例保护，避免多开抢端口

## Android 版

### 安装

1. 下载 `C240Pro.apk`
2. 允许安装未知来源应用
3. 打开后自动扫描并连接 C240 Pro

### 要求

| 项 | 要求 |
|---|---|
| 系统 | Android 8.0 及以上 |
| 蓝牙 | 手机需支持 BLE |
| 权限 | 首次启动申请蓝牙扫描/连接权限（Android 12 以下为定位权限） |

### 与 Windows 版的差异

| 功能 | Windows | Android |
|---|---|---|
| 实时曲线 / PD 分析 / 报文表格 | ✅ | ✅ 完全一致 |
| 数据导出 | Win32 原生「另存为」 | 系统「创建文档」对话框（SAF） |
| 启动速度 | 约 3~6 秒（单文件需解压） | 约 1 秒 |
| 后台运行 | 窗口在即运行 | 息屏后可能被系统挂起，回来会自动重连 |

### 注意

- 手机版与电脑版**不要同时连接同一台 C240 Pro**（设备是单连接）
- 换充电器后需重新插拔一次，能力表才会刷新（软件**不缓存**能力表，避免显示上一只头的旧数据）

## 使用方法

1. 解压到桌面或 D 盘（**不要放 `C:\Program Files\`**，程序要在自己目录写日志）
2. 双击 `PowerZ-Host.exe`
3. 打开 C240 Pro 电源，并在手机微信小程序里**断开连接**
4. 软件自动扫描连接；扫不到就点右上角「扫描设备」
5. 关闭窗口即退出程序

| 设备 | Power-Z C240 Pro（或广播相同 GATT 服务 UUID 的同族设备） |

## 常见问题

**Q：扫不到设备**
A：C240 Pro 是单连接设备，被手机小程序占用时会停止广播。先在小程序里断开，再点「扫描设备」。

**Q：PDO / eMarker 一直是空的**
A：这两项只在 PD 协商时上报。设备已进入稳定供电或固定档位输出时，CC 线上没有协商流量，为空属正常现象。重新插拔一次即可触发。

**Q：RDO 不刷新**
A：RDO 是协商时下发的请求，只在重新插拔/协商时更新。界面上会标注「收到于 X 秒前」，当前实时工作点请看仪表页。

**Q：曲线不动但数字在变**
A：按 Ctrl+F5 强制刷新页面。

**Q：启动时 Windows 弹出「已保护你的电脑」**
A：exe 未做代码签名。点「更多信息」→「仍要运行」即可。杀毒软件如有误报，请加白。

## 技术构成

| 层 | 技术 |
|---|---|
| Windows 蓝牙 | Python + bleak（走 WinRT） |
| Android 蓝牙 | Kotlin + BluetoothGatt |
| Android 界面 | WebView + 本地 NanoHTTPD 服务（复用同一套 index.html） |
| 本地服务 | Python 标准库 `http.server` + SSE 推送 |
| 界面 | HTML / CSS / JavaScript + ECharts |
| 窗口 | pywebview（Win32 窗口 + WebView2 内核） |
| 打包 | PyInstaller（onefile / onedir） |

设备识别**一律走 GATT 服务 UUID**（`0000af01` 数据特征 / `0000af02` 控制特征），不依赖 MAC 地址或蓝牙名，同型号不同设备均可自动识别。

### 目录结构

```
src/
  pz_host.py       服务主体：BLE 连接、HTTP/SSE、窗口控制、导出
  pz_protocol.py   协议解码：遥测、PD 帧、PDO/RDO/eMarker、采样率指令
  web/
    index.html     界面（Fluent 2 设计，单文件无构建依赖）
    echarts.min.js ECharts 5
```
